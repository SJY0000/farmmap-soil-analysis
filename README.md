# 🌱 기후변화에 따른 경상남도 재배작물 변화 분석 및 작물 추천 시스템

> 팜맵 공간정보 및 토양검정 데이터를 활용한 기후변화 대응 농업 정책 제언

---

## 📌 프로젝트 개요

기후변화로 인한 기온 상승과 강수 패턴 변화는 농업 환경에 큰 영향을 미치고 있습니다.  
본 프로젝트는 경상남도 18개 시·군의 팜맵 공간정보(2020~2025)와 토양검정 데이터를 분석하여  
재배작물의 변화 추이를 파악하고, 기후변화에 적합한 작물 추천 및 정책 방향을 제시합니다.

---

## 🎯 분석 목표

- 연도별 경상남도 재배작물 변화 추이 분석 (2020~2025)
- 토양 화학성(pH, 유기물, 유효인산 등) 변화와 작물 변화의 상관관계 분석
- 기후변화에 적합한 대체 작물 추천
- 지속 가능한 농업을 위한 정책 제언

## 🔧 주요 컬럼 설명

### 팜맵 공간정보

| 컬럼 | 설명 |
|---|---|
| `CLSF_NM` | 작물 분류명 (논, 밭, 과수 등) |
| `STDG_ADDR` | 소재지 주소 |
| `PNU` | 필지 고유번호 (토양검정 조회 키) |
| `AREA` | 필지 면적 (㎡) |
| `center_x / center_y` | Korea 2000 좌표 (API 조회용) |
| `lon / lat` | WGS84 위경도 |
| `geometry_wkt` | 도형 좌표 (지도 시각화용) |

### 토양검정 데이터

| 컬럼 | 설명 |
|---|---|
| `acidity` | 산도 (pH) |
| `ormtCont` | 유기물 함량 |
| `vdphdy` | 유효인산 |
| `rlfzKlusq` | 칼륨 (K) |
| `rlfzLmusq` | 칼슘 (Ca) |
| `rlfzMgusq` | 마그네슘 (Mg) |
| `elcd` | 전기전도도 (EC) |

## 🛠️ 사용 기술

- **Python** - 데이터 수집 및 전처리
- **pyproj** - 좌표계 변환 (Korea 2000 → WGS84)
- **requests** - 공공데이터 API 호출
- **pandas** - 데이터 분석

---

## 📊 분석 방향

1. **작물 변화 분석** : 연도별 필지 수, 면적 기준 작물 비중 변화
2. **토양 상태 분석** : 토양검정 데이터로 지역별 토양 화학성 현황 파악
3. **상관관계 분석** : 기후 데이터와 작물 변화, 토양 변화 연계 분석
4. **작물 추천** : 토양 조건과 기후변화 시나리오 기반 적합 작물 도출
5. **정책 제언** : 분석 결과 기반 경상남도 농업 정책 방향 제시
